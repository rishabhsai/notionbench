Methodology

📐

k=3 independent trials per task × config — no “retry then grade.” We report avg@3 with a 95% Wilson interval on the solve rate (the ± range), and pass^3: the share of tasks solved in all three trials — a reliability measure, not a luck measure.

Every cell is scored by deterministic, programmatic verification — static typechecks, offline behavioral checks (ntn workers exec --local, canonical-intents comparison for Notion-as-Code), and live workspace-state assertions run host-side, never visible to the agent. No LLM judges anywhere.

Task set, oracles, and QC foils are open — github.com/rishabhsai/notionbench.
