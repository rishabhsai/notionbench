# Ledger 2.4.0

Released 2026-08-04.

## Added
- Bulk export of reconciled entries as CSV.
- A `--since` flag on `ledger sync`.

## Fixed
- Rounding drift on multi-currency journals.
- The nightly reconciliation no longer double-counts refunds.

## Known issues
- Exports over 50k rows time out; chunk them for now.
